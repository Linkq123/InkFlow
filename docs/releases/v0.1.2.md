# InkFlow 0.1.2

## 版本概览

InkFlow 0.1.2 重点打磨长文写作的输入流畅度、启动速度、会话恢复与键盘操作体验。

## 更新

- 编辑缓冲区改用 CodeMirror `Text` 持久文本结构，普通按键不再把全文转换为字符串。
- 字数统计、大纲生成和远程图片检测合并为停止输入 300ms 后执行的 Worker 任务，并丢弃过期版本结果。
- 新增本地会话恢复，优先恢复活动文档，其余标签最多两个并发加载。
- 命令面板、快速打开、工作区搜索、文件菜单和对话框统一键盘与焦点行为。
- 多标签支持水平滚动、活动标签自动可见和全部标签列表。
- 保存失败通知支持重试和关闭；打字机模式与空白文档引导正式进入界面。
- 增加 5MB/10 万行性能夹具和 Windows 本地性能脚本，性能数据不发送遥测。

## 修复

- 修复初始化期间第二次打开请求可能遗漏或乱序的问题。
- 修复输入法组合期间命令筛选或快捷操作干扰中文输入的问题。
- 修复文件树行菜单无法完整使用键盘操作、关闭后焦点不能返回的问题。
- 修复快速输入、切换文档或关闭弹层时过期异步结果和焦点状态可能回写的问题。
- 修复长文分析在 Worker 不可用时可能阻塞主线程的问题。
