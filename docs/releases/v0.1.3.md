# InkFlow 0.1.3

## 版本概览

InkFlow 0.1.3 面向 Agent 与自动化工作流补齐完整的无头 CLI，同时强化桌面端与 CLI 共用的数据安全、渲染、资源和并发写入边界，并启用新的 InkFlow 品牌 Logo 与 Windows 图标。

## 更新

- 新增独立 `inkflow-cli.exe`，覆盖文档读取、分析、搜索、事务编辑、写入与另存为，以及工作区、图片资源、恢复、设置、会话、渲染、导出和桌面启动能力。
- 建立稳定的 `inkflow.cli/v1` JSON/JSONL 契约，提供 `capabilities`、JSON Schema 自发现、明确退出码、`--dry-run`、修订哈希保护、`--root` 路径边界和隔离数据目录。
- 桌面端与 CLI 共用 Markdown 净化、KaTeX、Mermaid、本地资源内嵌和 PDF 打印管线；HTML、PDF 与片段渲染按需启动隐藏 WebView2 进程，普通 CLI 命令不加载桌面运行时。
- NSIS 安装包和便携 ZIP 现在同时包含桌面程序与 CLI；交互安装可选择将安装目录加入当前用户 PATH，默认不修改。
- 设置、会话、恢复记录、待迁移资源和工作区路径变更增加跨进程协调，条件写入和最终目录身份核验覆盖桌面端与 CLI。
- 预览和导出新增响应式 `picture` / `srcset` 本地资源处理，并支持 Mermaid SVG 图片内嵌与 PDF 打印前的有界图片解码等待。
- 使用正式 `logo.png` 更新 README、欢迎页、Windows 桌面图标、文件关联和安装器图标，并提供可重复生成和校验脚本。

## 修复

- 修复保存、另存为、资源写入与工作区重命名或回收站操作并发时可能写回旧路径、误报成功或覆盖外部修改的问题。
- 修复强制写入或导出期间目标被移动、删除或父目录被替换后可能在旧位置重新创建文件的问题。
- 修复另存为处理引用式图片、HTML 图片、`srcset`、空格、字符引用以及字面 `%`、`&` 路径时可能复制失败、链接失效或残留资源的问题。
- 修复远程图片可通过响应式候选、Mermaid 元数据或生成 SVG 绕过默认阻止策略，以及仅有远程候选时预览无提示空白的问题。
- 修复恢复索引损坏、并发限频、系统时间回拨和配额清理场景下快照可能被遗漏、重复写入或过早清理的问题。
- 修复 CLI 在 Unicode 文本位置、旧编码与 UTF-16 BOM、任务和表格结构编辑、stdout 管道关闭、取消以及部分成功场景中的契约和数据安全问题。
- 修复初始化期间连续收到文件与工作区打开请求时可能丢失、覆盖或改变到达顺序的问题。
