# Markdown 兼容说明

InkFlow 的源文件遵循 CommonMark/GFM，不保存额外富文本状态，也不写入专有语法。预览由 Unified/Remark/Rehype 生成，实时融合层只改变屏幕装饰，不改变文档文本。

| 语法 | 编辑 | 实时融合 | 预览/导出 | 说明 |
|---|---:|---:|---:|---|
| 段落、换行、分隔线 | 是 | 是 | 是 | 保留原始换行风格 |
| ATX 标题 | 是 | 是 | 是 | 光标所在行显示 `#` |
| 粗体、斜体、删除线 | 是 | 是 | 是 | 支持选区工具条与快捷键 |
| 行内代码、代码围栏 | 是 | 是 | 是 | 围栏离开光标后显示只读代码块，点击回源码；语言包按需加载 |
| 有序/无序列表 | 是 | 轻量样式 | 是 | 不自动重排编号 |
| 任务列表 | 是 | 可点击 | 是 | 点击直接修改 `[ ]` / `[x]` |
| 链接 | 是 | 轻量样式 | 是 | 外部链接交给系统浏览器 |
| 本地图片 | 是 | 懒加载 | 是 | 默认相对路径；资源由 Rust 限域读取 |
| 远程图片 | 是 | 按文档授权 | 按文档授权 | 默认阻止网络加载，授权只在当前会话生效 |
| GFM 表格 | 是 | 可交互表格 | 是 | 悬浮可增删行列；点击表格回源码 |
| 脚注 | 是 | 源码 | 是 | 使用标准脚注语法 |
| YAML Front Matter | 是 | 源码 | 隐藏元数据块 | 不解析为 InkFlow 私有字段 |
| 行内/块数学公式 | 是 | KaTeX | KaTeX | 使用 `$…$` 与 `$$…$$` |
| Mermaid 围栏 | 是 | 视口内懒渲染 | 是 | `securityLevel: strict`；融合、预览和导出都按当前文档作用域加载本地 `img` 与序列图所有非 `@` 的 `icon`，流程图 Iconify 标识符保持原语义；离线内置 `inkflow:document` 与 `logos:github-icon`；远程图片按文档授权，失败或未授权时保留源码块；正文字体变化会重新渲染 |
| 原始 HTML | 是 | 源码 | 净化后显示 | `script`、事件处理器等危险内容被移除 |

## 保真规则

- 打开后不编辑直接保存时，编码、BOM、CRLF/LF 和末尾换行保持不变。
- UTF-8、UTF-8 BOM、UTF-16 LE/BE 被明确识别；其他 Windows 文本编码通过编码探测读取，并按原编码保存。
- 未知扩展语法和解析错误原样留在 Markdown 中。实时融合 Widget 渲染失败时回退到可见源码，不会修改内容。
- 单个代码、Mermaid、公式或表格块超过 200KB 时保持源码显示，不创建大型 Widget；语法树尚未就绪或围栏未闭合时，主线程回退查找同时受 500 行和 200,000 字符预算限制，表格范围扫描也采用相同预算，避免每次输入重复扫描长文。
- InkFlow 不自动格式化表格、列表、Front Matter 或整个文档。只有用户显式执行表格行列命令或资源迁移时，相关局部文本才会变化。
- 资源迁移生成的相对图片路径如果包含空格或括号，会使用 CommonMark 的 `<路径>` 目标形式，避免文件名破坏图片语法；文件名中的字面 `%` 会写为 `%25`，因此类似 `%20` 的合法名称不会被误解码为空格。该系统改写会同步映射到撤销/重做历史。预览或导出渲染器把空格序列化为 `%20` 后，资源边界会执行一次 UTF-8 URL 解码，并在解码结果上重新检查协议、绝对路径和允许根目录。
- “另存为”通过 CommonMark 解析事件和源码范围识别行内 Markdown、引用式 Markdown 或 HTML `<img>` 本地图片，并只改写解析器确认的图片目标；正文、行内/围栏代码、转义示例和普通链接中的同名文本保持不变。原文档属于当前工作区时允许复制工作区内的 `../images` 等相对资源；缺失、远程或越过文档/工作区允许范围的引用保持原样。原 Markdown 被外部删除不会阻止当前编辑缓冲区另存为；其父目录仍在时仍会尝试复制可访问资源。

- 图片迁移准确保留平衡括号、反斜杠转义、嵌套图片说明及原有标题，只替换完整目标范围。图片说明中的 HTML 属性、注释、代码及链接由 CommonMark 解析范围界定，其中的方括号不会导致漏迁移。HTML `img/src`、`img/srcset` 和 `source/srcset` 支持带引号、无引号及跨行属性；另存为期间继续编辑时，前端会把相同范围的资源改写合并到最新正文。前后端共用 `tests/fixtures/image-rewrites.json` 回归样例。
- 另存为期间只改变图片语法、属性引号或等价字符引用时，迁移按目标匹配并按当前语法编码，保留标题、密度描述符和新输入。Markdown 转义与字符引用单次解码，生成路径中的字面百分号不重复解码；源 URL 中的 `%xx` 与字面字符保持区分，避免误改旧版字面百分号文件名。`tests/fixtures/image-rewrite-merges.json` 共用于保存状态合并和应用保存回归测试。

## 安全边界

- HTML 预览先解析原始 HTML，再通过 Rehype 白名单净化。
- 本地图片最大 50MB，且必须位于对应文档目录或恢复区文档子目录；仅当文档自身属于当前工作区时才允许读取工作区内资源。规范化后的路径不能越过对应边界。
- 远程图片默认先在 `template` 惰性片段中解析渲染 HTML，再把 `img/src`、`img/srcset`、`source/srcset` 等可发起请求的远程属性改为惰性属性；Markdown 行内及引用式图片检测支持 Alt 文本、引用标签和图片目标中的 CommonMark 反斜杠转义，也支持 Alt 中的平衡嵌套方括号，因此 `![a [nested]](https\://…)` 及带转义标签的引用定义都可正常触发授权提示。列表或块引用容器内的引用定义及冒号后换行书写的目标会被识别，同名标签遵循首定义优先；检测会跳过转义图片、行内代码、缩进代码以及非 Mermaid 的顶层、列表或块引用内围栏代码中的示例。Mermaid 的图片节点元数据会按 Mermaid 自身的单行流式映射、多行块映射分支使用 YAML `JSON_SCHEMA` 解析，因此合法的多行本地图片不会被误判，转义后的 `img` 键、序列图 `icon` 键、锚点/别名和双引号反斜杠续行仍会触发远程图片授权；HTML 图片标签和 Markdown 图片标签也会在调用 Mermaid 渲染器前检查，未授权时不会进入可能发起请求的渲染流程。生成的 SVG 还会再次移除远程 `image/href`、`image/xlink:href`、`use/href` 和 `use/xlink:href` 属性。Markdown 图片目标只解码带完整分号的 CommonMark 字符引用，检测随后按浏览器最终 URL 规则处理反斜杠、制表符、换行符、首尾 C0 控制字符、原始 HTML 字符引用、未加引号属性以及 `https:/host`、`https:host` 等非标准网络引用；无分号数字引用不会被错误升级为远程 URL。属性值包含 `>`、原始 HTML 使用 `<picture>` 等情况同样不会先联网或漏掉授权提示。实时融合加载本地或已授权远程图片时复用同一严格目标解码；按文档授权后，Windows CSP 允许实际加载 HTTP、HTTPS 及相应协议相对图片。阻止提示的全文检测在停止输入 180ms 后交给与预览共用的渲染 Worker；输入文档 ID、正文和授权状态未变化时不会因自动保存状态切换而重复调度；没有图片语法候选的文档会直接返回，其余文档检查同一净化管线的输出。同类型新请求会终止过期 Worker 任务，并在新实例中重放另一类型仍有效的请求，避免旧全文解析积压；预览的图片与 Mermaid 异步水合在每个等待阶段校验渲染版本，实时融合的 Mermaid Widget 也会在销毁后终止后续异步渲染，因此过期任务不能把旧授权应用到新 DOM 或继续启动图表渲染。这些路径不进入每次击键的主线程热路径，也不会重复打包 Markdown 解析依赖。授权和远程内容都不会写入 Markdown。
- 实时融合、普通预览和 HTML/PDF 导出都先通过同一受限文档资源加载器解析 Mermaid 元数据中的本地 `img` 以及序列图中会生成 SVG 图片 URL 的所有非 `@` `icon`，转换为 `data:` URL 后再交给 strict 渲染器；锚点/别名和块标量按完整 YAML 映射解析并规范化回写。加载被拒绝、映射无法安全解析或读取失败时整张图保留惰性源码块，未经解析的本地 URI 不会进入 Mermaid。流程图等使用的 Iconify `prefix:name` 与 `@` 开头的内嵌引用保留原值。图标包只从应用内离线注册，不因未知 `prefix:name` 联网；当前支持 `inkflow:document` 与 `logos:github-icon`，其他标识显示 Mermaid 的未知图标。三种入口的 Mermaid 初始化与渲染同时使用 InkFlow 队列和 Mermaid 自身队列，并运行在可销毁的同源 iframe 独立 realm 中，导出主题、解析器状态和字体不会被并发预览覆盖；单次渲染 30 秒未完成时调用方会降级保留源码并销毁整个挂起 realm，下一任务创建全新实例，因此不会让旧 Promise 与新初始化并发，也不会永久禁用后续渲染。远程引用仍按文档授权，生成 SVG 继续进行二次净化。
- Mermaid 元数据规范化回写时保留集合的 YAML 锚点/别名引用，避免嵌套或循环别名被递归展开；本地 `img`/`icon` 仍替换为受限加载器返回的 `data:` URL。
- HTML/PDF 导出复用同一净化后渲染结果，并把可访问的本地图片转换为 `data:` URL；单文件 HTML 同时内嵌 KaTeX 样式和字体。
